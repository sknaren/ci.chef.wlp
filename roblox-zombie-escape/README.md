# Zombie Escape (Roblox Studio)

A complete starter for a zombie escape game: night-time town, houses full of loot,
guns, chasing zombies and an escape zone that unlocks once you hold 3 keycards.
Everything is generated by script, so no models or assets are needed.

I could not watch the reference video, so this is built from the description
"zombie escape game with guns, houses and loot". Tell me what differs and I'll adjust it.

## Install (manual, ~5 minutes)

Create a **Baseplate** place in Roblox Studio, then add scripts with the exact type, name and parent below
(copy each file's contents from `src/`):

| File | Type | Parent / Name |
|---|---|---|
| `ReplicatedStorage/Config.lua` | ModuleScript | ReplicatedStorage → `Config` |
| `ReplicatedStorage/RemoteHub.lua` | ModuleScript | ReplicatedStorage → `RemoteHub` |
| `ServerScriptService/GameManager.server.lua` | Script | ServerScriptService → `GameManager` |
| `ServerScriptService/Modules/*.lua` (5 files) | ModuleScript | ServerScriptService → new Folder `Modules` → `MapBuilder`, `LootService`, `ZombieService`, `WeaponService`, `WeaponFactory` |
| `StarterPlayerScripts/GunClient.client.lua` | LocalScript | StarterPlayer → StarterPlayerScripts → `GunClient` |
| `StarterPlayerScripts/HUD.client.lua` | LocalScript | StarterPlayer → StarterPlayerScripts → `HUD` |

Then press **Play**. (With Rojo: `rojo serve` using `default.project.json`.)

## How to play
- Spawn in the middle with a Pistol. Equip with `1`, click to shoot, `R` to reload.
- Search houses (walk up, hold **E**) for ammo, medkits, Shotgun and Rifle.
- 3 blue **keycards** are hidden in random houses. Collect all, then reach the green **ESCAPE** beam in the far corner.
- Dying resets your weapons, ammo and keycards. Kills and Escapes show on the leaderboard.

## Tweaking
All numbers (zombie speed/health/damage, weapon stats, loot odds, keycards needed, map size) are in `Config`.
